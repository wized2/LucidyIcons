Lucidy Icons

Android icon pack for Lawnchair and friends — icons from the official Lucide set (MIT), not redrawn by hand.

Download APK Source
How to apply

Install the APK → Lawnchair settings → Icon pack → Lucidy Icons.

What’s inside

100+ Lucide stroke icons (phone, messages, browser, camera, settings, social stand-ins, and more) plus component mappings for common apps.
